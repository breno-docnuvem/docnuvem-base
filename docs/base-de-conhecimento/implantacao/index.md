# Processo de Implantação

Passo a passo completo da implantação de um novo cliente Docnuvem, do recebimento dos dados até a entrega ao cliente.

## Quando se aplica

Sempre que uma nova instância Docnuvem é vendida e precisa ser configurada e entregue a um cliente (planos Standard e Enterprise).

## Padrão de acompanhamento (lembrete + cobrança)

Sempre que uma etapa depender de um retorno do cliente e ele não responder em tempo razoável, seguir o padrão: primeiro um **lembrete** (tom leve, oferecendo apoio), depois, se ainda não houver resposta, uma **cobrança** (tom mais firme, mencionando o impacto no cronograma). As páginas de cada etapa que têm esse padrão trazem os dois textos prontos em "Se não houver resposta".
