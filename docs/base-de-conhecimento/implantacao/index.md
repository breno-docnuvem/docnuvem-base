# Processo de Implantação

Passo a passo completo da implantação de um novo cliente Docnuvem, do recebimento dos dados até a entrega ao cliente.

## Quando se aplica

Sempre que uma nova instância Docnuvem é vendida e precisa ser configurada e entregue a um cliente (planos Standard e Enterprise).

2. Configuração inicial da instância
    1. [02 - Configurações da empresa](02-configuracoes-da-empresa.md)
    2. [03 - Outras configurações](03-outras-configuracoes.md)
    3. [04 - Configurações avançado](04-configuracoes-avancado.md)
    4. [05 - Funcionalidades Enterprise](05-funcionalidades-enterprise.md) — *apenas planos Enterprise*
    5. [06 - Cadastro do primeiro usuário](06-cadastro-do-primeiro-usuario.md)
3. Primeiro contato com o cliente
    1. [07 - Cadastro do contato no Digisac](07-cadastro-do-contato-no-digisac.md)
    2. [08 - Script de primeiro contato](08-script-de-primeiro-contato.md)
    3. [09 - Envio da playlist (Standard)](09-envio-da-playlist-standard.md) — *apenas plano Standard*
