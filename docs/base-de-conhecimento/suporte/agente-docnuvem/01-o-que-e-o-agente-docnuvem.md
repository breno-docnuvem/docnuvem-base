# 01 - O que é o Agente Docnuvem

## Quando se aplica

Antes de decidir instalar o Agente em um cliente — para entender o que a ferramenta faz e como ela se diferencia do Sincronizador.

## O que é

O Agente é um programa instalado no computador do cliente que monitora uma pasta local e envia automaticamente todo o seu conteúdo para o Docnuvem. Ele funciona através da API de integração do Docnuvem.

## Diferença em relação ao Sincronizador

O Sincronizador mantém uma sincronia de mão dupla entre a plataforma e o computador. O Agente funciona apenas em uma via — do computador para o Docnuvem.

## Formas de instalação

| Modo | Comportamento |
|---|---|
| **Programa convencional** | Roda apenas enquanto o usuário Windows responsável estiver logado. Não funciona com o usuário deslogado. |
| **Serviço do Windows** | Roda mesmo sem nenhum usuário logado, desde que o computador/servidor esteja ligado. |

## Contexto comercial
