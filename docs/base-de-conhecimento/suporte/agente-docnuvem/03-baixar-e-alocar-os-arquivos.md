# 03 - Baixar e alocar os arquivos

## Quando se aplica

Depois de decidido que o Agente será instalado (ver [02 - Quando instalar o Agente Docnuvem](02-quando-instalar-o-agente-docnuvem.md)) — primeiro passo prático, igual para os dois modos de instalação (programa convencional ou serviço do Windows).

## 1. Baixar a última versão

**Repositório:** [drive.google.com/drive/folders/1o__NMigwygon4Ezub9cSUuVpn_osNTxh](https://drive.google.com/drive/folders/1o__NMigwygon4Ezub9cSUuVpn_osNTxh?usp=sharing)

Acessar o repositório e, dentro da pasta da versão mais atual do robô, baixar a pasta "agente-docnuvem". O download vem como um arquivo .zip contendo a pasta do agente.

![Pasta "agente-docnuvem" para download no repositório do Google Drive.](images/03-baixar-e-alocar-os-arquivos/01-download-pasta-agente-docnuvem.png)

## 2. Alocação dos arquivos

Acessar o computador do cliente via AnyDesk e extrair o conteúdo de "agente-docnuvem.zip" para a pasta onde o programa será instalado. Recomenda-se usar a pasta Documentos do Windows, pois isso evita erros de permissão.

![Extração dos arquivos do Agente na máquina do cliente.](images/03-baixar-e-alocar-os-arquivos/02-extrair-arquivos-cliente.png)
