# Chamados que resolvi e como resolvi

Registro de problemas de suporte já resolvidos, para consulta rápida. Lista viva — cresce conforme novos casos forem documentados.

## Problemas ao logar com o usuário

Se nenhum dos meios convencionais de login resolver, verificar se existem dois usuários com o mesmo login, diferindo só na caixa (maiúsculas/minúsculas) — por exemplo, `pedro` e `PEDRO` — mesmo que um deles esteja bloqueado.
