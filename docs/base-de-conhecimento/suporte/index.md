# Suporte — visão geral

Processos operacionais do time de Suporte.

## Processos

- [Agente Docnuvem (robô)](agente-docnuvem/index.md) — quando e como instalar o robô que envia arquivos automaticamente para o Docnuvem.
- [Sincronizador Docnuvem](sincronizador/index.md) — passo a passo de instalação do Sincronizador e do controle de permissões por usuário.
- [API Docnuvem (Importação)](api-importacao.md) — referência dos endpoints de importação, geração de documento por modelo, assinatura eletrônica e consulta/download de documentos.
- **Integrações específicas de clientes** — documentação de APIs feitas sob medida para um cliente específico. Por ter dados de cliente, fica fora deste repositório, numa pasta compartilhada no Google Drive — peça o link ao Breno.
