# 02 - Como se localizar no repositório

## Quando se aplica

Sempre que for baixar o instalador, procurar uma versão anterior, ou consultar o que mudou entre versões do Sincronizador.

## Repositório

[drive.google.com/drive/folders/1nVb_sFIwXLARTo_iH96bG1mbHaNuXf_n](https://drive.google.com/drive/folders/1nVb_sFIwXLARTo_iH96bG1mbHaNuXf_n?usp=sharing)

## Estrutura das pastas

**estrutura padrão** — a estrutura padrão do Sincronizador, com os arquivos necessários para instalação e funcionamento do sistema. Ao atualizar o Sincronizador, essa estrutura deve ser mantida, substituindo apenas os arquivos que fazem parte da nova versão.

**versão atual** — sempre contém o `.jar` da versão atual do programa, o arquivo de configurações padrão, um `readme.md` com as informações da versão (correções, atualizações e adições) e um arquivo de instalação com o passo a passo e alguns pontos úteis. O nome da pasta segue o padrão "ver. \[nº da versão\]\([data da versão\)".

**versões anteriores** — todas as versões anteriores, com a estrutura da versão atual no que for aplicável.

**vídeos** — vídeos que podem ajudar na instalação ou na correção de bugs.

**CHANGELOG.md** — o controle das alterações de cada versão.

## Na prática

Para uma instalação nova, é só montar os arquivos a partir de "estrutura padrão" e "versão atual" (ver [04 - Baixar os arquivos de instalação](04-baixar-os-arquivos-de-instalacao.md)). Para saber se um comportamento é esperado ou uma novidade recente, o `CHANGELOG.md` costuma responder mais rápido do que abrir o `.jar` ou testar na mão.
