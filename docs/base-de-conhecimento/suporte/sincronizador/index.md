# Sincronizador Docnuvem

Programa instalado no computador do cliente que mantém uma pasta local sincronizada em mão dupla com o Docnuvem — é o módulo vendido comercialmente hoje (ver [01 - O que é o Sincronizador](01-o-que-e-o-sincronizador.md); para o outro programa parecido, de uso interno e só em casos pontuais, ver [Agente Docnuvem (robô)](../agente-docnuvem/index.md)).

## Quando se aplica

Sempre que estiver instalando, atualizando ou dando suporte ao Sincronizador em uma máquina de cliente — desde a primeira instalação até a ativação (opcional) do controle de permissões por usuário.
