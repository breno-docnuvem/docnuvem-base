# Fluxos essenciais

Use esta página como roteador. Ela não substitui o passo a passo do manual.

## Encontrar e abrir um documento

1. Use [Meus Documentos](../manual/04-meus-documentos.md) quando souber onde o arquivo está.
2. Use [Busca Avançada](../manual/05-busca-avancada.md) quando precisar combinar filtros.
3. Verifique diretório, permissões e filtros ativos se o resultado não aparecer.
