# Glossário

| Termo | Significado operacional |
| --- | --- |
| Ações | Menu usado para acessar operações disponíveis em arquivos, diretórios ou registros, como editar, mover, solicitar, excluir ou vincular informações. |
| Agendamento | Configuração que programa uma solicitação para ocorrer automaticamente em uma data ou com uma recorrência definida. |
| Auditoria | Histórico usado para consultar eventos e alterações realizados no sistema. |
| Busca avançada | Recurso para localizar arquivos e diretórios usando filtros. |
| Checklist | Lista de verificação com itens, responsáveis e opções de progresso. |
| Contato | Registro de uma pessoa ou empresa externa que pode receber solicitações, links de envio, assinaturas ou notificações. |
| Diretório | Pasta para organizar documentos e aplicar regras de acesso e processo. |
| Documento | Arquivo armazenado no Docnuvem. |
| Formulário | Estrutura de campos vinculada a informações adicionais de um documento. |
| Grupo de permissões | Conjunto de acessos aplicado a usuários com perfil semelhante. |
| IADoc | Assistente inteligente do Docnuvem para buscas, análise documental e dúvidas operacionais. |
| Modelo de documento | Configuração reutilizável para padronizar documentos. |
| Modelo de diretório | Configuração reutilizável para padronizar pastas e sua estrutura. |
| Modelo de solicitação | Configuração que define documentos pedidos em um processo de coleta. |
| Metadado | Informação adicional usada para classificar ou descrever um documento. |
| Recorrência | Configuração que repete uma solicitação em períodos definidos. |
| Solicitação | Processo de pedir documentos, preenchimentos ou assinaturas. |
| Solicitação de envio | Processo usado para pedir que um destinatário envie documentos ao Docnuvem por meio de um link de acesso. |
| Solicitação de preenchimento | Processo usado para enviar um documento ou formulário para que outra pessoa preencha as informações necessárias. |
| Tipo de documento | Cadastro que classifica documentos e pode definir metadados e assinatura. |
| WhatsApp integrado | Recurso que permite enviar links de solicitação ou de assinatura pelo WhatsApp, quando a integração estiver configurada. |
