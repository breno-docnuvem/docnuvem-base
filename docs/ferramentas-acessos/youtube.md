# Acesso ao YouTube Docnuvem

## O que é

Canal do YouTube do Docnuvem, usado para publicar os vídeos de apoio aos processos de Suporte e Implantação (instalação, atualização, solução de problemas etc.) — os mesmos vídeos incorporados nas páginas da Base de Conhecimento Interna.

## Como acessar

As instruções de acesso estão neste documento: [Acesso ao YouTube Docnuvem (Google Docs)](https://docs.google.com/document/d/1ftt9ZuxX5xic0cgE8XgD3yld0bMqHkjd8-cNokc5to8/edit?usp=sharing)

> O acesso fica nesse documento (e não replicado aqui) por ser informação de acesso a uma plataforma de terceiros — evita duplicar credenciais/links sensíveis dentro do repositório do site.

## Se travar
