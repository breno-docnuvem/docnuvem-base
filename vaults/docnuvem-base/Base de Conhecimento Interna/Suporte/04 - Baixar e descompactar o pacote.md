# 04 - Baixar e descompactar o pacote

## Quando se aplica

Depois de ativado o módulo na empresa (ver [[03 - Antes de instalar (ativar o módulo na empresa)]]) — primeiro passo prático da instalação, na máquina do cliente.

## Passo a passo

1. Baixar o pacote de dentro da pasta **"versão atual"** do repositório (ver [[02 - Como se localizar no repositório]]).
2. Descompactar em uma pasta fixa da máquina, por exemplo `C:\DocnuvemSincronizador\`.

## Na prática

O pacote já vem com o Java embutido — não é preciso instalar Java na máquina do cliente separadamente.
