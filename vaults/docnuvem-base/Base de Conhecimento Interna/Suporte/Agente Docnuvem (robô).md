# Agente Docnuvem (robô)

Programa instalado no computador do cliente que monitora uma pasta local e envia automaticamente todo o seu conteúdo para o Docnuvem, usado apenas em situações específicas de Suporte/Implantação — não é o módulo vendido comercialmente hoje (ver [[01 - O que é o Agente Docnuvem]]).

## Quando se aplica

Sempre que estiver avaliando se um cliente precisa do Agente instalado, ou executando essa instalação. Não confundir com o Sincronizador (módulo comercial atual) — os dois fazem coisas parecidas, mas o Agente só é usado nos casos listados em [[02 - Quando instalar o Agente Docnuvem]].
