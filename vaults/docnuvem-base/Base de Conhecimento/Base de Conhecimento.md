# Base de Conhecimento

Área de consulta rápida para apoiar a equipe durante a operação do Docnuvem. O **Manual DOCNUVEM** continua sendo a fonte dos procedimentos detalhados; esta área organiza conceitos, decisões, dúvidas frequentes e diagnóstico para consulta humana e futura IA.

## Como usar

1. Comece por [[01 - Visão geral do sistema]].
2. Para executar uma tarefa, consulte [[02 - Fluxos essenciais]] e abra o procedimento do manual indicado.
3. Para um erro ou comportamento inesperado, consulte [[03 - Diagnóstico e troubleshooting]].
4. Para uma pergunta curta, consulte [[04 - FAQ operacional]].
5. Para termos do sistema, consulte [[05 - Glossário operacional]].

## Regra de ouro

Não transformar hipótese em instrução. Quando a resposta não estiver documentada ou depender da configuração da instância, registrar a limitação e encaminhar para a pessoa responsável pelo suporte.
