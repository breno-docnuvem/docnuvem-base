# Fazendo login no sistema

Para acessar o Docnuvem, siga os passos abaixo.

## 1. Acessar a página de login

Abra seu navegador e acesse a página de login do sistema.

![[Manual DOCNUVEM/images/acessando-o-sistema/fazendo-login-no-sistema/01-pagina-de-login.png]]

*Figura 1. Página de login do Docnuvem, com os campos de login e senha.*

## 2. Informar usuário e senha

Digite seu **nome de usuário** e sua **senha** nos campos correspondentes.

[Print sugerido: images/acessando-o-sistema/fazendo-login-no-sistema/02-usuario-e-senha.png | Instrução: mostrar os campos de usuário e senha preenchidos com dados fictícios.]

## 3. Entrar no sistema

Após inserir as credenciais, clique em **Entrar** ou pressione a tecla **Enter** no teclado.

[Print sugerido: images/acessando-o-sistema/fazendo-login-no-sistema/03-botao-entrar.png | Instrução: mostrar a tela de login com uma seta vermelha apontando para o botão **Entrar**.]

Se as informações estiverem corretas, o usuário será redirecionado para a página principal do sistema.
