# Resolução de problemas de login

Alguns problemas podem impedir o acesso ao Docnuvem. Veja as situações mais comuns abaixo.

## Erro de login

Se o nome de usuário ou a senha forem informados incorretamente, o sistema solicitará uma nova tentativa de login.

[Print sugerido: images/acessando-o-sistema/resolucao-de-problemas-de-login/01-erro-de-login.png | Instrução: mostrar a mensagem de erro exibida quando o usuário ou a senha estiverem incorretos.]

## Redefinição de senha

Caso tenha esquecido sua senha, clique em **Esqueceu a senha? Clique aqui!** na página de login e siga as instruções para redefini-la pelo e-mail cadastrado.

[Print sugerido: images/acessando-o-sistema/resolucao-de-problemas-de-login/02-esqueceu-a-senha.png | Instrução: mostrar a página de login com uma seta vermelha apontando para a opção **Esqueceu a senha? Clique aqui!**.]

[Print sugerido: images/acessando-o-sistema/resolucao-de-problemas-de-login/03-redefinicao-de-senha.png | Instrução: mostrar a tela de redefinição de senha ou envio de e-mail para recuperação.]

Se o problema continuar, entre em contato com o suporte técnico para obter assistência.
