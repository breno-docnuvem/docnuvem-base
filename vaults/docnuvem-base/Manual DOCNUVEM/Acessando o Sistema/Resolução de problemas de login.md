# Resolução de problemas de login

Alguns problemas podem impedir o acesso ao Docnuvem. Veja as situações mais comuns abaixo.

## Erro de login

Se o nome de usuário ou a senha forem informados incorretamente, o sistema solicitará uma nova tentativa de login.

![[Manual DOCNUVEM/images/acessando-o-sistema/resolucao-de-problemas-de-login/01-erro-de-login.png]]

*Figura 1. Mensagem exibida quando o login ou a senha estão incorretos.*

## Redefinição de senha

Caso tenha esquecido sua senha, clique em **Esqueceu a senha? Clique aqui!** na página de login e siga as instruções para redefini-la pelo e-mail cadastrado.

![[Manual DOCNUVEM/images/acessando-o-sistema/resolucao-de-problemas-de-login/02-esqueceu-a-senha.png]]

*Figura 2. Opção Esqueceu a senha? Clique aqui! na página de login.*

![[Manual DOCNUVEM/images/acessando-o-sistema/resolucao-de-problemas-de-login/03-redefinicao-de-senha.png]]

*Figura 3. Tela de redefinição de senha, com o campo de e-mail.*

Se o problema continuar, entre em contato com o suporte técnico para obter assistência.
