# Certificados

A tela **Certificados** permite visualizar os certificados inseridos no Docnuvem durante o cadastro de [[Cadastro de Empresas, ARs e Agências]].

Essa tela lista os certificados cadastrados, indica se estão vigentes ou vencidos e mostra a empresa, AR ou agência à qual cada certificado pertence.
