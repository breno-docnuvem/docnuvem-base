# Como configurar data de vencimento para Contratos

Para que um contrato apareça na tela **Contratos** com controle de validade, o modelo do documento deve possuir um item de data de vencimento.

## 1. Acessar o modelo de documento

No menu principal, acessar **Meus modelos** e clicar em **Modelo de documento**.

Depois, criar ou editar o modelo utilizado para gerar contratos.

[Print sugerido: images/arquivos/como-configurar-data-de-vencimento-para-contratos/01-modelo-documento.png | Instrução: mostrar a tela de Modelo de documento com um modelo de contrato aberto para edição.]

## 2. Adicionar o item de vencimento

Na configuração de itens do modelo, adicionar um item com o tipo **Data de vencimento**.

Para detalhes sobre itens de modelo, consulte [[Como configurar itens no Modelo de documento]].

![[Manual DOCNUVEM/images/arquivos/como-configurar-data-de-vencimento-para-contratos/02-item-data-vencimento.png]]

*Figura 1. Tipo de item Data de vencimento, na área de itens do modelo.*

## 3. Salvar o modelo

Após configurar o item, clicar em **Salvar**.

[Print sugerido: images/arquivos/como-configurar-data-de-vencimento-para-contratos/03-salvar-modelo.png | Instrução: mostrar o botão Salvar no modelo de documento.]

## Resultado esperado

Os contratos criados a partir desse modelo passam a ter data de validade definida para acompanhamento na tela **Contratos**.
