# Como configurar posição das assinaturas para assinatura em massa

Para usar assinatura em massa com posicionamento correto, o tipo de documento precisa ter assinantes e posição de assinatura configurados.

## 1. Acessar o tipo de documento

No menu principal, acessar **Tipos cadastrados** e clicar em **Tipo de documento**.

Depois, selecionar o tipo de documento que será configurado para assinatura.

[Print sugerido: images/arquivos/como-configurar-posicao-das-assinaturas-para-assinatura-em-massa/01-tipo-documento.png | Instrução: mostrar a listagem de tipos de documento com um tipo selecionado para edição.]

## 2. Abrir configurações de assinatura

No cadastro do tipo de documento, acessar a aba **Configurações de assinatura**.

[Print sugerido: images/arquivos/como-configurar-posicao-das-assinaturas-para-assinatura-em-massa/02-configuracoes-assinatura.png | Instrução: mostrar a aba Configurações de assinatura aberta.]

## 3. Adicionar assinantes

Na seção **Assinantes**, clicar em **Adicionar** e selecionar os assinantes necessários.

Importante: a configuração de posição de assinatura só é habilitada quando há assinantes cadastrados no tipo de documento.

[Print sugerido: images/arquivos/como-configurar-posicao-das-assinaturas-para-assinatura-em-massa/03-adicionar-assinantes.png | Instrução: mostrar a seção Assinantes com o botão Adicionar destacado.]

## 4. Configurar a posição das assinaturas

Clicar em **Configurar posição das assinaturas**.

Se o documento já tiver sido configurado anteriormente, clicar em **Reconfigurar posição das assinaturas**.

[Print sugerido: images/arquivos/como-configurar-posicao-das-assinaturas-para-assinatura-em-massa/04-configurar-posicao-assinaturas.png | Instrução: mostrar os botões Configurar posição das assinaturas ou Reconfigurar posição das assinaturas destacados.]

## 5. Posicionar as assinaturas

Posicionar os campos de assinatura no documento conforme necessário.

[Print sugerido: images/arquivos/como-configurar-posicao-das-assinaturas-para-assinatura-em-massa/05-posicionar-assinaturas.png | Instrução: mostrar a tela de posicionamento de assinaturas com os campos de assinatura sobre o documento.]

## Resultado esperado

O tipo de documento fica configurado para uso em fluxos de assinatura em massa.
