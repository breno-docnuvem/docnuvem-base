# Como configurar regras de Envio Inteligente

As regras de **Envio Inteligente** definem como documentos processados pela IA Documental serão direcionados para pastas.

## 1. Acessar o modelo de diretório

No menu principal, acessar **Meus modelos** e clicar em **Modelo de diretório**.

[Print sugerido: images/arquivos/como-configurar-regras-de-envio-inteligente/01-menu-modelo-diretorio.png | Instrução: mostrar o menu Meus modelos com a opção Modelo de diretório destacada.]

## 2. Selecionar o modelo

Na listagem, selecionar o modelo de diretório que receberá as regras.

[Print sugerido: images/arquivos/como-configurar-regras-de-envio-inteligente/02-selecionar-modelo-diretorio.png | Instrução: mostrar a listagem de modelos de diretório com um modelo selecionado.]

## 3. Abrir a configuração de regras

Clicar em **Configurar Regras de Envio Inteligente** para definir as regras e metadados do envio.

[Print sugerido: images/arquivos/como-configurar-regras-de-envio-inteligente/03-configurar-regras-envio-inteligente.png | Instrução: mostrar o botão ou opção Configurar Regras de Envio Inteligente destacado no modelo de diretório.]

## 4. Definir regras e metadados

Configurar os critérios que a IA utilizará para direcionar os documentos às pastas do modelo.

[Print sugerido: images/arquivos/como-configurar-regras-de-envio-inteligente/04-regras-e-metadados.png | Instrução: mostrar a tela de configuração das regras de Envio Inteligente com campos de regra e metadados destacados.]

## Resultado esperado

Os documentos processados pela IA Documental podem ser direcionados automaticamente conforme as regras configuradas.
