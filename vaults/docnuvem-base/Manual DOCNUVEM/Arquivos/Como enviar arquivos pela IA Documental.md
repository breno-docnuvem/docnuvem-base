# Como enviar arquivos pela IA Documental

Este guia explica como subir documentos para processamento pela IA Documental.

## 1. Acessar a tela

No menu principal, acessar **Arquivos** e clicar em **IA Documental**.

[Print sugerido: images/arquivos/como-enviar-arquivos-pela-ia-documental/01-menu-ia-documental.png | Instrução: mostrar o menu Arquivos com a opção IA Documental destacada.]

## 2. Enviar documentos

Arrastar os documentos do computador para a área indicada ou clicar na área de envio para selecionar os arquivos.

[Print sugerido: images/arquivos/como-enviar-arquivos-pela-ia-documental/02-area-envio-arquivos.png | Instrução: mostrar a área de envio da IA Documental com indicação para arrastar ou selecionar documentos.]

## Resultado esperado

Os documentos são enviados para processamento pela IA Documental.
