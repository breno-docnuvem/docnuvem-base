# Como filtrar documentos na IA Documental

Use os filtros da IA Documental para localizar documentos enviados para processamento.

## 1. Abrir os filtros

Na tela **IA Documental**, clicar no balão **Filtrar**.

[Print sugerido: images/arquivos/como-filtrar-documentos-na-ia-documental/01-balao-filtrar.png | Instrução: mostrar a tela IA Documental com o balão Filtrar destacado.]

## 2. Informar critérios de busca

Preencher os filtros disponíveis, como status, data, responsável, tipo, nome ou outros critérios exibidos na tela.

[Print sugerido: images/arquivos/como-filtrar-documentos-na-ia-documental/02-campos-de-filtro.png | Instrução: mostrar o painel de filtros expandido com os principais campos destacados.]

## 3. Aplicar os filtros

Clicar em **Filtrar** para atualizar a listagem.

[Print sugerido: images/arquivos/como-filtrar-documentos-na-ia-documental/03-aplicar-filtros.png | Instrução: mostrar o botão Filtrar no painel de filtros.]

## Resultado esperado

A listagem exibe apenas os documentos que correspondem aos critérios informados.
