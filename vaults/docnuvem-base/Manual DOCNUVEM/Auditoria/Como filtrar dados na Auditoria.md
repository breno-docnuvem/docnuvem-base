# Como filtrar dados na Auditoria

Use os filtros da Auditoria para encontrar ações específicas no histórico do sistema.

## 1. Abrir os filtros

Na tela de **Auditoria**, clicar no balão **Filtrar**.

[Print sugerido: images/auditoria/como-filtrar-dados-na-auditoria/01-balao-filtrar.png | Instrução: mostrar a tela de Auditoria com o balão Filtrar destacado.]

## 2. Definir os critérios de busca

Informar os critérios desejados, como usuário, período ou outros campos disponíveis na tela.

Esses critérios ajudam a localizar ações realizadas por usuários específicos ou em intervalos determinados.

[Print sugerido: images/auditoria/como-filtrar-dados-na-auditoria/02-criterios-de-busca.png | Instrução: mostrar o painel de filtros da Auditoria com campos de usuário e período destacados.]

## 3. Aplicar o filtro

Clicar em **Filtrar** para atualizar a listagem.

[Print sugerido: images/auditoria/como-filtrar-dados-na-auditoria/03-aplicar-filtro.png | Instrução: mostrar o botão Filtrar no painel de filtros da Auditoria.]

## Resultado esperado

A listagem passa a exibir apenas as ações compatíveis com os critérios informados.
