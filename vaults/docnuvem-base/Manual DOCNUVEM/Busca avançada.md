# Busca avançada

O recurso de **Busca avançada** permite localizar documentos, diretórios e dados no Docnuvem aplicando filtros específicos por nome, tipo, modelo, checklist, metadados, solicitações, assinaturas, formulários e regras associadas.

Use este módulo quando precisar encontrar informações com critérios mais detalhados do que a busca simples da tela atual.
