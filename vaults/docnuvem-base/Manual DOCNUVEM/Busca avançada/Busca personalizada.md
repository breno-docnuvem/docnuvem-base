# Busca personalizada

A **Busca personalizada** permite pesquisar usando filtros previamente configurados no Docnuvem.

Use esta opção quando houver uma busca cadastrada para um cenário recorrente, como documentos de um tipo específico, diretórios com determinados critérios ou combinações de filtros usadas com frequência.

## 1. Abrir a aba Busca personalizada

Na tela de **Busca avançada**, acessar a aba **Busca personalizada**.

[Print sugerido: images/busca-avancada/busca-personalizada/01-aba-busca-personalizada.png | Instrução: mostrar a aba Busca personalizada selecionada na tela de Busca avançada.]

## 2. Selecionar a busca cadastrada

Selecionar a busca personalizada desejada. As opções disponíveis dependem das buscas cadastradas previamente no sistema.

Caso nenhuma busca esteja disponível, será necessário cadastrá-la antes de utilizar este filtro. Para isso, consulte [[Como cadastrar uma Busca personalizada]].

## 3. Executar a pesquisa

Depois de selecionar a busca, clicar em **Buscar** para carregar os resultados.

[Print sugerido: images/busca-avancada/busca-personalizada/02-resultados-busca-personalizada.png | Instrução: mostrar a área de resultados após a execução de uma busca personalizada.]

## Resultado esperado

O Docnuvem exibe os resultados correspondentes à busca personalizada selecionada.
