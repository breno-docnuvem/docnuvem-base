# Busca por arquivos

A **Busca por arquivos** permite localizar documentos usando filtros próprios de arquivos, processos associados e informações complementares.

## 1. Abrir a aba Arquivos

Na tela de **Busca avançada**, clicar na aba **Arquivos**.

[Print sugerido: images/busca-avancada/busca-por-arquivos/01-aba-arquivos.png | Instrução: mostrar a aba Arquivos selecionada na Busca avançada.]

## 2. Informar os parâmetros principais

Preencher os campos necessários para restringir a busca. Os principais parâmetros são:

- **Nome do documento**
- **Tipo de documento**
- **Modelo de documento**
- **Código do documento**

[Print sugerido: images/busca-avancada/busca-por-arquivos/02-parametros-busca-arquivos.png | Instrução: mostrar os campos principais de busca por arquivos destacados.]

## 3. Aplicar filtros adicionais

Quando necessário, usar filtros complementares como **Metadados**, **Checklists**, **Solicitação de preenchimento de documento**, **Assinaturas** e **Formulários**.

Para entender cada grupo de filtro, consulte [[Filtros para documentos na Busca avançada]].

## 4. Buscar ou limpar filtros

Depois de configurar os critérios, clicar em **Buscar**.

Para remover os critérios informados e recomeçar a pesquisa, clicar em **Limpar Filtros**.

[Print sugerido: images/busca-avancada/busca-por-arquivos/03-resultados-arquivos.png | Instrução: mostrar a área de resultados da busca por arquivos após clicar em Buscar.]

## Resultado esperado

O Docnuvem lista os arquivos que atendem aos critérios informados.
