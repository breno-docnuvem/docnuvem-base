# Filtros para diretórios na Busca avançada

Os filtros de diretórios permitem localizar pastas considerando identificação, checklists, regras e processos associados.

## Parâmetro principal

Use o campo **Nome do diretório** para localizar pastas pelo nome.

[Print sugerido: images/busca-avancada/filtros-para-diretorios-na-busca-avancada/01-parametros-diretorios.png | Instrução: mostrar o campo Nome do diretório na aba Diretórios.]

## Checklists

O grupo **Checklists** permite filtrar diretórios vinculados a checklists e itens de checklist.

Também é possível indicar se o checklist está **Concluído**, usando opções como **Todos**, **Sim** ou **Não**, conforme a tela apresentar.

## Regras de Envio Inteligente

O grupo **Regras de Envio Inteligente** permite localizar diretórios por regras configuradas para recebimento e organização de documentos.

Campos comuns:

- **Regra tipo de documento**
- **Regra período**
- **Regra especial**
- **Regra de metadado**
- **Condição**
- **Valor do metadado**

Na opção **Regra período**, a tela pode exibir combinações como **Anual**, **Anual/Mensal**, **Anual/Trimestral** e **Anual/Trimestral/Mensal**.

Na opção **Condição**, use critérios como **Contém** ou **Exatamente igual**, conforme o resultado esperado.

[Print sugerido: images/busca-avancada/filtros-para-diretorios-na-busca-avancada/02-regras-envio-inteligente.png | Instrução: mostrar o grupo Regras de Envio Inteligente na aba Diretórios, com os campos principais destacados.]

## Solicitação de preenchimento de documento

Este grupo filtra diretórios relacionados a solicitações de preenchimento.

Campos comuns:

- **Nome do solicitante**
- **E-mail do solicitante**
- **Modelo de documento**
- **Status da solicitação**
- **Solicitado a partir de**
- **Solicitado até**
- **Preenchido de**
- **Preenchido até**

## Solicitação de envio do documento

Este grupo filtra diretórios relacionados a solicitações de envio de documentos.

Campos comuns:

- **Nome do solicitante**
- **E-mail do solicitante**
- **Solicitado a partir de**
- **Solicitado até**
- **Modelo de solicitação**
- **Status da solicitação**
- **Item do modelo de solicitação**
- **Status do item**

## Agendamento modelo de envio do documento

Este grupo filtra diretórios relacionados a agendamentos de solicitação de documentos.

Campos comuns:

- **Nome do solicitante**
- **E-mail do solicitante**
- **Agendado a partir de**
- **Agendado até**
- **Modelo de solicitação**
- **Tipo de agendamento**

O campo **Tipo de agendamento** pode exibir opções como **Diário**, **Semanal**, **Quinzenal**, **Mensal** e **Anual**.

[Print sugerido: images/busca-avancada/filtros-para-diretorios-na-busca-avancada/03-filtros-solicitacoes-diretorios.png | Instrução: mostrar os grupos de solicitação e agendamento na aba Diretórios.]

## Resultado esperado

O usuário entende qual grupo de filtro deve usar para localizar diretórios na **Busca avançada**.
