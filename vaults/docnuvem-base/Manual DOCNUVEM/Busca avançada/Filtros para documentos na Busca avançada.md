# Filtros para documentos na Busca avançada

Os filtros de documentos permitem localizar arquivos considerando informações do próprio documento e processos vinculados a ele.

## Parâmetros principais

Use estes campos para encontrar documentos por identificação direta:

- **Nome do documento**: pesquisa pelo nome do arquivo.
- **Tipo de documento**: restringe a busca a um tipo cadastrado.
- **Modelo de documento**: filtra documentos gerados ou associados a um modelo.
- **Código do documento**: pesquisa pelo código identificador do documento.

## Metadados

O grupo **Metadados** permite pesquisar documentos por informações vinculadas ao tipo ou ao formulário do documento.

Use este filtro quando precisar encontrar arquivos com valores específicos registrados em campos personalizados.

## Checklists

O grupo **Checklists** permite filtrar documentos vinculados a checklists e itens de checklist.

Também é possível indicar se o checklist está **Concluído**, usando opções como **Todos**, **Sim** ou **Não**, conforme a tela apresentar.

## Solicitação de preenchimento de documento

Este grupo filtra documentos relacionados a solicitações de preenchimento.

Campos comuns:

- **Nome do solicitante**
- **E-mail do solicitante**
- **Modelo de documento**
- **Status da solicitação**
- **Solicitado a partir de**
- **Solicitado até**
- **Preenchido de**
- **Preenchido até**

## Assinaturas

O grupo **Assinaturas** permite localizar documentos conforme os dados e o andamento de fluxos de assinatura.

Campos comuns:

- **Nome do assinante**
- **CPF do assinante**
- **E-mail do assinante**
- **Status da assinatura**
- **Status do assinante**
- **Solicitado a partir de**
- **Solicitado até**
- **Assinaturas de**
- **Assinaturas até**
- **Validade de**
- **Validade até**

## Formulários

O grupo **Formulários** permite buscar documentos vinculados a formulários e itens de formulário específicos.

Use este filtro quando precisar localizar documentos por respostas ou campos preenchidos no formulário.

## Resultado esperado

O usuário entende qual grupo de filtro deve usar para localizar documentos na **Busca avançada**.
