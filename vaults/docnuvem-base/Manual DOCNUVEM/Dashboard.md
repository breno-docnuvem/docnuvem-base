# Dashboard

O Dashboard do Docnuvem apresenta uma visão geral das principais informações da instância. Ele reúne indicadores, quadros e gráficos para ajudar o usuário a acompanhar assinaturas, checklists, vencimentos, solicitações e atividades recentes.

Além da visualização resumida, o Dashboard permite acessar listagens detalhadas a partir dos próprios gráficos. Dessa forma, o usuário consegue sair de uma visão geral para uma análise mais específica sem precisar navegar manualmente por outros menus.
