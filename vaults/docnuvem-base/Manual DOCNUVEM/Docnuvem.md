# Docnuvem

Este manual foi estruturado para orientar o usuário na utilização das principais funcionalidades do Docnuvem. As seções apresentam fluxos práticos, com passos sequenciais, imagens de apoio e observações importantes para facilitar a execução das atividades no sistema.

## Pré-requisito

Antes de executar qualquer procedimento, verifique se o usuário possui permissão de acesso à funcionalidade desejada. Algumas opções podem não aparecer no menu ou nas ações quando o perfil não possui a permissão correspondente.

## Como utilizar este manual

- Utilize o sumário para acessar diretamente a funcionalidade desejada.
- Leia as orientações de pré-requisito, importante, dica e resultado esperado antes de concluir um processo.
- Siga os passos na ordem apresentada, principalmente em fluxos que dependem de cadastros prévios, como modelos, formulários, contatos e tipos de documento.
- Consulte o glossário ao final do manual sempre que encontrar um termo técnico ou uma nomenclatura do sistema.

## Conceitos principais

| Termo | Descrição |
| --- | --- |
| Documento | Arquivo armazenado no Docnuvem, como contratos, certificados, comprovantes, relatórios ou documentos enviados por terceiros. |
| Diretório | Pasta utilizada para organizar documentos e aplicar permissões, solicitações, checklists e regras de automação. |
| Tipo de Documento | Cadastro que classifica documentos e pode definir metadados, regras de assinatura e comportamentos específicos. |
| Formulário | Estrutura de campos usada para registrar informações adicionais em documentos que não foram gerados diretamente por um processo interno. |
| Modelo de Solicitação | Configuração que define quais documentos devem ser solicitados em um processo de coleta. |
| Recorrência | Configuração que permite repetir uma solicitação automaticamente em períodos definidos, como diário, semanal, mensal ou anual. |
