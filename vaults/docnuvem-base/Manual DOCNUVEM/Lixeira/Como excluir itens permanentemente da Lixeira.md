# Como excluir itens permanentemente da Lixeira

Use este guia para remover definitivamente arquivos ou diretórios da Lixeira antes do prazo de exclusão automática.

## 1. Selecionar os itens

Na tela da **Lixeira**, marcar o checkbox ao lado dos arquivos ou diretórios que deseja excluir permanentemente.

[Print sugerido: images/lixeira/como-excluir-itens-permanentemente-da-lixeira/01-selecionar-itens.png | Instrução: mostrar a listagem da Lixeira com checkboxes de arquivos ou diretórios selecionados para exclusão permanente.]

## 2. Abrir o menu Ações

Clicar em **Ações**.

[Print sugerido: images/lixeira/como-excluir-itens-permanentemente-da-lixeira/02-menu-acoes.png | Instrução: mostrar o botão Ações na tela da Lixeira destacado.]

## 3. Excluir permanentemente

Selecionar **Excluir selecionados** para remover definitivamente os itens marcados.

Também é possível usar **Excluir todos** para excluir permanentemente mais de um arquivo ou diretório de uma vez, conforme a opção disponível no menu **Ações**.

[Print sugerido: images/lixeira/como-excluir-itens-permanentemente-da-lixeira/03-excluir-selecionados.png | Instrução: mostrar o menu Ações com as opções Excluir selecionados e Excluir todos destacadas.]

## Resultado esperado

Os itens selecionados são removidos permanentemente e não ficam mais disponíveis para restauração.
