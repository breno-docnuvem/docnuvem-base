# Cadastro de Busca personalizada

O cadastro de **Busca personalizada** permite salvar filtros de pesquisa para reutilização na [[Busca avançada]].

Use esta funcionalidade quando a equipe faz consultas recorrentes e precisa encontrar arquivos ou diretórios com mais rapidez, sem configurar os mesmos filtros a cada busca.
