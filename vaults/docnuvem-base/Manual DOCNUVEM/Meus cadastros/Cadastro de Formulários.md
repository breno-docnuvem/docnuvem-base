# Cadastro de Formulários

O cadastro de **Formulários** permite criar estruturas de campos para registrar informações de documentos que não foram gerados por processos internos da plataforma.

Use formulários para padronizar dados, controlar vencimentos e facilitar a consulta de informações vinculadas a documentos.
