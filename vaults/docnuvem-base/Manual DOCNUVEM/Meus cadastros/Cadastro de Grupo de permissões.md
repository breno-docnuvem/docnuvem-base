# Cadastro de Grupo de permissões

O cadastro de **Grupo de permissões** permite organizar permissões de acesso para vários usuários ao mesmo tempo.

Use grupos para definir quais diretórios, documentos, checklists, assinaturas, tarefas e outras funcionalidades poderão ser acessados por usuários com o mesmo perfil de atuação.
