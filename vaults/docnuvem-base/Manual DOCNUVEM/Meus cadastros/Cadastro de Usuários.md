# Cadastro de Usuários

O cadastro de **Usuários** permite controlar quem pode acessar o Docnuvem e quais áreas, diretórios e funcionalidades cada pessoa poderá utilizar.

Use este cadastro para manter o acesso ao sistema organizado, seguro e adequado à função de cada usuário.
