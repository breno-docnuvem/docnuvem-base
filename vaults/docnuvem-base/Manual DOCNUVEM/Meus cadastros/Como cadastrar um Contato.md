# Como cadastrar um Contato

Este guia explica como criar um novo contato no Docnuvem.

## 1. Acessar o cadastro

No menu principal, acessar **Meus cadastros** e clicar em **Contatos**.

![[Manual DOCNUVEM/images/meus-cadastros/como-cadastrar-um-contato/01-menu-contatos.png]]

*Figura 1. Menu Meus cadastros, com a opção Contatos destacada.*

## 2. Iniciar um novo contato

Na tela de listagem, clicar em **Cadastrar novo contato**.

![[Manual DOCNUVEM/images/meus-cadastros/como-cadastrar-um-contato/02-cadastrar-novo-contato.png]]

*Figura 2. Listagem de contatos, com o botão Cadastrar novo contato destacado.*

## 3. Preencher os dados do contato

Informar os dados solicitados no formulário.

Confira se as informações estão corretas, principalmente os dados que serão usados em solicitações para o contato.

![[Manual DOCNUVEM/images/meus-cadastros/como-cadastrar-um-contato/03-dados-do-contato.png]]

*Figura 3. Formulário Cadastrar novo contato.*

## 4. Salvar o contato

Após preencher os campos, clicar em **Salvar**.

[Print sugerido: images/meus-cadastros/como-cadastrar-um-contato/04-botao-salvar.png | Instrução: mostrar o botão Salvar no cadastro de contato.]

## Resultado esperado

O contato fica cadastrado e disponível para uso nos processos do Docnuvem.
