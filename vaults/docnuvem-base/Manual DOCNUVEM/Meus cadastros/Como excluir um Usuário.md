# Como excluir um Usuário

Use este guia para remover um usuário cadastrado.

## 1. Localizar o usuário

Acessar a listagem de **Usuários** e usar o balão **Filtrar** para encontrar o registro.

[Print sugerido: images/meus-cadastros/como-excluir-um-usuario/01-filtrar-usuario.png | Instrução: mostrar a listagem de usuários com o filtro aberto.]

## 2. Acionar a exclusão

Na coluna **Ações**, clicar no ícone de lixeira do usuário.

[Print sugerido: images/meus-cadastros/como-excluir-um-usuario/02-acao-excluir.png | Instrução: mostrar a coluna Ações com o ícone de lixeira destacado.]

## 3. Confirmar a exclusão

Na notificação exibida pelo sistema, confirmar a exclusão.

[Print sugerido: images/meus-cadastros/como-excluir-um-usuario/03-confirmar-exclusao.png | Instrução: mostrar a mensagem de confirmação de exclusão com a opção de confirmar destacada.]

## Resultado esperado

O usuário é removido da listagem.
