# Como importar Contatos

Use a importação para cadastrar vários contatos a partir de uma planilha.

## 1. Acessar a tela de contatos

No menu principal, acessar **Meus cadastros** e clicar em **Contatos**.

[Print sugerido: images/meus-cadastros/como-importar-contatos/01-listagem-contatos.png | Instrução: mostrar a listagem de contatos.]

## 2. Abrir a importação

Clicar em **Importar contatos**.

[Print sugerido: images/meus-cadastros/como-importar-contatos/02-importar-contatos.png | Instrução: mostrar o botão Importar contatos destacado.]

## 3. Baixar a planilha padrão

Na tela de importação, clicar em **Baixar planilha padrão**.

Use essa planilha como modelo para preencher os dados no formato esperado pelo Docnuvem.

[Print sugerido: images/meus-cadastros/como-importar-contatos/03-baixar-planilha-padrao.png | Instrução: mostrar a tela de importação com o botão Baixar planilha padrão destacado.]

## 4. Preencher a planilha

Preencher a planilha com os contatos que serão importados.

Os campos **Telefone do contato**, **CPF** e **CNPJ** devem ser preenchidos com suas respectivas máscaras, incluindo pontos, barras, traços ou parênteses quando aplicável.

## 5. Selecionar e importar o arquivo

Após salvar a planilha preenchida, selecionar o arquivo no campo de importação e clicar em **Importar contatos**.

[Print sugerido: images/meus-cadastros/como-importar-contatos/04-selecionar-e-importar-planilha.png | Instrução: mostrar o campo de seleção do arquivo e o botão Importar contatos destacados.]

## 6. Conferir a mensagem do sistema

O Docnuvem exibirá uma mensagem informando se os contatos foram importados.

Se a importação não for concluída, revise a planilha e confira se todos os dados foram informados corretamente.

[Print sugerido: images/meus-cadastros/como-importar-contatos/05-mensagem-importacao.png | Instrução: mostrar a mensagem de sucesso ou erro da importação de contatos.]

## Resultado esperado

Os contatos da planilha são adicionados à listagem de contatos.
