# Como agrupar documentos

O agrupamento permite reunir vários arquivos de uma mesma pasta em um único documento. Antes de concluir, é possível definir o nome do novo arquivo e ajustar a ordem dos documentos que o compõem.

## 1. Selecionar os documentos

Na tela **Meus documentos**, abra a pasta que contém os arquivos. Marque os documentos que deseja agrupar.

[Print sugerido: images/meus-documentos/como-agrupar-documentos/01-selecionar-documentos.png | Instrução: mostrar uma pasta aberta na tela Meus documentos, com vários documentos selecionados para agrupamento.]

## 2. Acessar a opção de agrupamento

Clique em **Ações** e selecione **Agrupar documentos**.

[Print sugerido: images/meus-documentos/como-agrupar-documentos/02-agrupar-documentos.png | Instrução: mostrar o botão Ações aberto, com a opção Agrupar documentos destacada por uma seta vermelha.]

## 3. Configurar o novo documento

Informe o nome do arquivo agrupado no campo disponível. Se necessário, marque **Mover documentos para lixeira após agrupar** para enviar os arquivos originais à lixeira depois da conclusão.

Na lista de documentos, ajuste a ordem dos arquivos conforme deseja que apareçam no novo documento.

[Print sugerido: images/meus-documentos/como-agrupar-documentos/03-configurar-agrupamento.png | Instrução: mostrar a tela de agrupamento com o campo de nome, a opção Mover documentos para lixeira após agrupar e a lista de arquivos. Destacar os controles usados para alterar a ordem dos documentos.]

## 4. Concluir o agrupamento

Confirme a operação para criar o novo documento agrupado na pasta atual.

## Resultado esperado

O Docnuvem cria um único arquivo com os documentos selecionados na ordem definida. Se a opção de mover para a lixeira estiver marcada, os arquivos originais são enviados para a lixeira.
