# Como criar documentos

A criação de documentos permite gerar um novo arquivo diretamente no Docnuvem a partir de um modelo de documento já cadastrado. Esse recurso é útil quando a organização utiliza documentos padronizados, como contratos, declarações, termos ou outros arquivos que seguem uma estrutura fixa.

## Pré-requisito

Antes de criar o documento, é necessário que o modelo de documento correspondente já esteja cadastrado no sistema. Para saber mais, consulte a seção [[Modelo de documento]].

## 1. Acessar a pasta de destino

Na tela **Meus documentos**, abra a pasta onde o novo documento deverá ser criado.

[Print sugerido: images/meus-documentos/como-criar-documentos/01-pasta-destino.png | Instrução: mostrar a pasta de destino aberta na tela Meus documentos.]

## 2. Selecionar a opção Criar documento

Clique no botão **Ações** e selecione a opção **Criar documento**.

[Print sugerido: images/meus-documentos/como-criar-documentos/02-criar-documento.png | Instrução: mostrar o botão Ações aberto com a opção Criar documento destacada por uma seta vermelha.]

## 3. Escolher o modelo de documento

Na tela exibida pelo sistema, selecione o modelo de documento que será usado para gerar o arquivo.

[Print sugerido: images/meus-documentos/como-criar-documentos/03-selecionar-modelo.png | Instrução: mostrar a tela de seleção do modelo de documento com um modelo destacado.]

## 4. Preencher os dados do documento

Preencha o formulário com as informações solicitadas pelo modelo e informe o título do documento que será criado.

[Print sugerido: images/meus-documentos/como-criar-documentos/04-preencher-formulario.png | Instrução: mostrar o formulário de criação do documento com os campos e o título do documento visíveis, sem expor dados sensíveis.]

## 5. Gerar o documento

Após preencher as informações, confirme a criação. O Docnuvem gera o PDF do arquivo e salva o documento na pasta selecionada.

[Print sugerido: images/meus-documentos/como-criar-documentos/05-documento-gerado.png | Instrução: mostrar a pasta de destino com o documento criado em PDF aparecendo na listagem.]

## Resultado esperado

O documento é criado em formato PDF a partir do modelo selecionado e passa a ficar disponível na pasta escolhida.
