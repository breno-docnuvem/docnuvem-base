# Como enviar uma solicitação pelo WhatsApp

Depois de criar uma solicitação de preenchimento, de envio de documentos ou de assinatura, é possível enviar o link ao destinatário pelo WhatsApp.

Existem duas formas de fazer esse envio:

- Usando um número já cadastrado na plataforma. Veja [[Como conectar o Whatsapp]].
- Pela API aberta, que dispara o WhatsApp que estiver logado na máquina em que a solicitação está sendo feita.

## 1. Criar a solicitação

Crie a solicitação normalmente, conforme o guia do tipo escolhido: [[Como solicitar o preenchimento de documentos]], [[Como solicitar o envio de documentos]] ou [[Como solicitar uma assinatura em um arquivo]].

Ao final, o ícone do WhatsApp passa a aparecer na coluna **Informações** da listagem.

![[Manual DOCNUVEM/images/meus-documentos/como-enviar-uma-solicitacao-pelo-whatsapp/01-icone-whatsapp.png]]

*Figura 1. Ícone do WhatsApp na coluna Informações.*

## 2. Clicar no ícone do WhatsApp

Clique no ícone do WhatsApp. O Docnuvem abre uma janela com as solicitações da pasta. Nas solicitações de assinatura com mais de um participante, a janela lista os participantes; com um só participante, o WhatsApp Web já é aberto para iniciar a conversa.

![[Manual DOCNUVEM/images/meus-documentos/como-enviar-uma-solicitacao-pelo-whatsapp/02-janela-solicitacoes.png]]

*Figura 2. Janela Solicitações, com o ícone do WhatsApp de cada destinatário.*

## 3. Iniciar a conversa

Se houver um número conectado como responsável pelos envios, o Docnuvem apenas informa que a solicitação foi enviada com sucesso.

Caso contrário, o WhatsApp Web é aberto com a mensagem pronta. Clique em **Iniciar conversa**. Se o aplicativo do WhatsApp não estiver instalado na máquina, o WhatsApp oferece baixá-lo ou continuar pelo **WhatsApp Web**.

## Importante

- O ícone do WhatsApp só aparece se o número de telefone do destinatário tiver sido informado. Mantenha os telefones dos contatos atualizados.
- O Docnuvem usa o perfil do WhatsApp que estiver logado na máquina no momento do envio. Confirme que é o perfil que realmente deve enviar a solicitação.

## Solicitações agendadas

As solicitações agendadas também podem ser integradas ao WhatsApp. Quando a automação está configurada, o link de envio é disparado para o WhatsApp do contato responsável sempre que um novo ciclo de recorrência começa, sem acionamento manual. É indicado para rotinas recorrentes de cobrança de documentos. Veja [[Como agendar solicitações de documentos]].
