# Como renomear documentos e diretórios

É possível alterar o nome de um arquivo ou de uma pasta diretamente na tela **Meus documentos**.

## 1. Acessar as opções do item

Localize o arquivo ou a pasta que deseja renomear. Clique com o botão direito do mouse sobre o item e selecione **Renomear**.

[Print sugerido: images/meus-documentos/como-renomear-documentos-e-diretorios/01-opcao-renomear.png | Instrução: mostrar o menu exibido ao clicar com o botão direito em um arquivo ou pasta, com a opção Renomear destacada por uma seta vermelha.]

## 2. Informar o novo nome

Digite o novo nome no campo exibido pelo Docnuvem.

[Print sugerido: images/meus-documentos/como-renomear-documentos-e-diretorios/02-informar-novo-nome.png | Instrução: mostrar a janela de renomeação com o campo para informar o novo nome destacado.]

## 3. Confirmar a alteração

Confirme a operação para salvar o novo nome.

## Resultado esperado

O arquivo ou a pasta passa a ser exibido com o novo nome na pasta atual.
