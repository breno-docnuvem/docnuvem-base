# Como solicitar o envio de documentos

A solicitação de envio de documentos permite pedir arquivos a um usuário ou contato e definir a pasta em que eles deverão ser armazenados no Docnuvem.

## Pré-requisito

Antes de criar a solicitação, é necessário ter um modelo de solicitação de documentos cadastrado. Para saber mais, consulte [[Modelo de solicitação]].

## 1. Localizar a pasta de destino

Na tela **Meus documentos**, localize a pasta onde os documentos solicitados deverão ser salvos.

[Print sugerido: images/meus-documentos/como-solicitar-o-envio-de-documentos/01-pasta-destino.png | Instrução: mostrar a tela Meus documentos com a pasta de destino selecionada.]

## 2. Selecionar a solicitação de envio

Clique com o botão direito na pasta e selecione **Solicitar envio de documentos**.

![[Manual DOCNUVEM/images/meus-documentos/como-solicitar-o-envio-de-documentos/02-solicitar-envio-de-documentos.png]]

*Figura 1. Menu da pasta, com a opção Solicitar envio de documentos destacada.*

## 3. Selecionar o modelo e informar os dados do documento

Na nova tela, selecione o modelo de solicitação e informe o nome do documento que será criado. Se necessário, defina também a data de vencimento da solicitação.

[Print sugerido: images/meus-documentos/como-solicitar-o-envio-de-documentos/03-dados-do-documento.png | Instrução: mostrar a tela de solicitação com os campos de modelo de solicitação, nome do documento e data de vencimento visíveis.]

## 4. Preencher os complementos do documento

O preenchimento dos campos complementares é opcional, pois eles também podem ser configurados diretamente no modelo de solicitação. Para saber mais, consulte [[Modelo de solicitação]].

[Print sugerido: images/meus-documentos/como-solicitar-o-envio-de-documentos/04-complementos-do-documento.png | Instrução: mostrar os campos de complemento exibidos após a seleção do modelo de solicitação, sem expor dados sensíveis.]

## 5. Definir o destinatário

No campo **Enviar formulário de preenchimento do modelo de documento para**, escolha o tipo de destinatário: **E-mail/Telefone**, **Usuário** ou **Contato**.

Ao selecionar **Contato**, informe o nome, o e-mail e o telefone do destinatário.

![[Manual DOCNUVEM/images/meus-documentos/como-solicitar-o-envio-de-documentos/05-definir-destinatario.png]]

*Figura 2. Janela de solicitação de envio, com as opções E-mail, Usuário e Contato.*

## 6. Adicionar o destinatário

Depois de preencher as informações, clique em **Adicionar** para incluir o destinatário na solicitação.

Para alterar as permissões ou informações de envio, consulte [[Solicitações e Compartilhamentos]].

![[Manual DOCNUVEM/images/meus-documentos/como-solicitar-o-envio-de-documentos/06-adicionar-destinatario.png]]

*Figura 3. Destinatário adicionado à solicitação, com o botão Adicionar destacado.*

## 7. Enviar a solicitação

Após adicionar o destinatário, clique em **Solicitar** para disparar a solicitação de envio de documentos.

[Print sugerido: images/meus-documentos/como-solicitar-o-envio-de-documentos/07-enviar-solicitacao.png | Instrução: mostrar o botão Solicitar destacado por uma seta vermelha na tela de solicitação.]

## Observação

Para acompanhar o andamento dos envios, consulte [[Significado dos ícones]].
