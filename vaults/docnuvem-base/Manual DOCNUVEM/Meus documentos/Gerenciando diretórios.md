# Gerenciando diretórios

Os diretórios podem ser gerenciados pela tela **Meus documentos**. As ações disponíveis podem incluir criar pasta, renomear, mover ou enviar o diretório para a lixeira, de acordo com as permissões do usuário.

## 1. Selecionar o diretório

Na tela **Meus documentos**, localize a pasta que deseja gerenciar.

[Print sugerido: images/meus-documentos/gerenciando-diretorios/01-diretorio-selecionado.png | Instrução: mostrar uma pasta selecionada na estrutura de diretórios.]

## 2. Abrir as ações da pasta

Clique no botão **Ações** da pasta ou clique com o botão direito do mouse sobre o nome do diretório.

[Print sugerido: images/meus-documentos/gerenciando-diretorios/02-acoes-diretorio.png | Instrução: mostrar o menu de ações de uma pasta aberto, destacando as opções disponíveis.]

## 3. Executar a ação desejada

Escolha a ação necessária, como **Criar pasta**, **Renomear**, **Mover** ou **Mover para lixeira**, e siga as instruções exibidas pelo sistema.

[Print sugerido: images/meus-documentos/gerenciando-diretorios/03-opcoes-diretorio.png | Instrução: mostrar as opções de gerenciamento disponíveis para um diretório.]

## Resultado esperado

O diretório é atualizado conforme a ação escolhida, mantendo a estrutura de pastas organizada no Docnuvem.
