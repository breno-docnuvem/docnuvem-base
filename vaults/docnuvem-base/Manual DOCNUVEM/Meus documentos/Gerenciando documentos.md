# Gerenciando documentos

Os documentos podem ser gerenciados diretamente pela tela **Meus documentos**. As ações disponíveis dependem das permissões do usuário e podem incluir opções como mover, renomear ou enviar o documento para a lixeira.

## 1. Localizar o documento

Na tela **Meus documentos**, navegue pela estrutura de pastas até encontrar o arquivo que deseja gerenciar.

[Print sugerido: images/meus-documentos/gerenciando-documentos/01-documento-localizado.png | Instrução: mostrar um documento localizado dentro de uma pasta na tela Meus documentos.]

## 2. Abrir as ações do documento

Para acessar as opções disponíveis, clique no botão **Ações** do documento ou clique com o botão direito do mouse sobre o nome do arquivo.

[Print sugerido: images/meus-documentos/gerenciando-documentos/02-acoes-documento.png | Instrução: mostrar o menu de ações de um documento aberto, destacando o botão Ações ou o menu exibido pelo clique direito.]

## 3. Escolher a ação desejada

Selecione a ação que deseja executar, como **Mover**, **Renomear** ou **Mover para lixeira**. Em seguida, siga as orientações exibidas pelo sistema.

[Print sugerido: images/meus-documentos/gerenciando-documentos/03-opcoes-documento.png | Instrução: mostrar as opções de gerenciamento disponíveis para um documento.]

## Resultado esperado

O Docnuvem executa a ação selecionada e atualiza a tela conforme a alteração realizada no documento.
