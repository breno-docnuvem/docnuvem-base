# Navegando nos diretórios

A navegação por diretórios permite acessar pastas, retornar a locais anteriores e entender o caminho atual dentro da estrutura de documentos.

## 1. Abrir uma pasta

Na tela **Meus documentos**, clique no nome da pasta que deseja acessar. O Docnuvem exibe o conteúdo do diretório selecionado.

[Print sugerido: images/meus-documentos/navegando-nos-diretorios/01-abrir-pasta.png | Instrução: mostrar uma pasta na tela Meus documentos com uma seta vermelha indicando o clique para abrir.]

## 2. Usar o caminho de navegação

Logo abaixo do campo **Buscar**, o sistema exibe o caminho até o diretório atual. Esse caminho ajuda o usuário a entender em qual pasta está navegando.

[Print sugerido: images/meus-documentos/navegando-nos-diretorios/02-caminho-navegacao.png | Instrução: mostrar o caminho de navegação abaixo do campo Buscar, destacando os nomes das pastas.]

## 3. Voltar para uma pasta anterior

Para retornar à pasta raiz ou a uma pasta anterior, clique sobre o nome desejado no caminho de navegação.

[Print sugerido: images/meus-documentos/navegando-nos-diretorios/03-voltar-pasta-anterior.png | Instrução: mostrar o caminho de navegação com uma seta vermelha indicando o nome da pasta que será clicada para voltar.]

## Resultado esperado

O usuário consegue navegar entre os diretórios, localizar documentos e retornar para pastas anteriores com facilidade.
