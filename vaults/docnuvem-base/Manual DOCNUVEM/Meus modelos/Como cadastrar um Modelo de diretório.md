# Como cadastrar um Modelo de diretório

Este guia explica como criar um novo modelo de diretório.

## 1. Acessar o cadastro

No menu principal, acessar **Meus modelos** e clicar em **Modelo de diretório**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-diretorio/01-menu-modelo-diretorio.png | Instrução: mostrar o menu Meus modelos com a opção Modelo de diretório destacada.]

## 2. Iniciar um novo modelo

Na tela de listagem, clicar em **Cadastrar novo modelo**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-diretorio/02-cadastrar-novo-modelo.png | Instrução: mostrar a listagem de modelos de diretório com o botão Cadastrar novo modelo destacado.]

## 3. Informar o nome

Definir o nome do modelo de diretório.

Use um nome claro para identificar a estrutura que será criada, como o nome de um setor, projeto ou padrão empresarial.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-diretorio/03-nome-do-modelo.png | Instrução: mostrar o campo de nome do modelo de diretório destacado.]

## 4. Salvar o modelo

Clicar em **Salvar**.

Após salvar, o sistema retorna para a listagem de modelos de diretório.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-diretorio/04-botao-salvar.png | Instrução: mostrar o botão Salvar no cadastro de modelo de diretório.]

## 5. Abrir o modelo criado

Na listagem, selecionar o modelo criado para configurar sua estrutura de pastas.

Ao abrir o modelo, o sistema exibe um balão com o nome do modelo e o botão **Ações**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-diretorio/05-modelo-criado-acoes.png | Instrução: mostrar o modelo de diretório aberto com o balão do nome do modelo e o botão Ações destacados.]

## Resultado esperado

O modelo de diretório fica criado e pronto para receber a estrutura de pastas.
