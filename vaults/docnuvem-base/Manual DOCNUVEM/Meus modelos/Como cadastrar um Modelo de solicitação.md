# Como cadastrar um Modelo de solicitação

Este guia explica como criar um novo modelo de solicitação de documentos.

## 1. Acessar o cadastro

No menu principal, acessar **Meus modelos** e clicar em **Modelo de solicitação**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-solicitacao/01-menu-modelo-solicitacao.png | Instrução: mostrar o menu Meus modelos com a opção Modelo de solicitação destacada.]

## 2. Iniciar um novo modelo

Na tela de listagem, clicar em **Cadastrar novo modelo**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-solicitacao/02-cadastrar-novo-modelo.png | Instrução: mostrar a listagem de modelos de solicitação com o botão Cadastrar novo modelo destacado.]

## 3. Informar os dados principais

Definir o nome do modelo e a quantidade de dias em que a solicitação ficará disponível.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-solicitacao/03-dados-principais.png | Instrução: mostrar os campos de nome do modelo e dias de disponibilidade da solicitação destacados.]

## 4. Adicionar documentos solicitados

Clicar em **Adicionar** para inserir um documento que será solicitado.

Para cada documento, informar a descrição, a subpasta onde o arquivo será salvo, se o envio será obrigatório e se a pessoa poderá enviar mais de um arquivo para esse documento.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-solicitacao/04-adicionar-documento-solicitado.png | Instrução: mostrar a área de documentos solicitados com o botão Adicionar e os campos do documento destacados.]

## 5. Salvar o modelo

Após revisar os dados e documentos solicitados, clicar em **Salvar**.

[Print sugerido: images/meus-modelos/como-cadastrar-um-modelo-de-solicitacao/05-botao-salvar.png | Instrução: mostrar o botão Salvar no cadastro de modelo de solicitação.]

## Resultado esperado

O modelo fica disponível para uso em solicitações de documentos e agendamentos de solicitação.
