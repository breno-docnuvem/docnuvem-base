# Como configurar arquivos no Modelo de documento

Use arquivos no modelo quando o documento gerado precisar receber anexos durante o preenchimento.

## 1. Adicionar solicitação de arquivo

Na área de arquivos, clicar em **Adicionar**.

Os arquivos enviados durante o preenchimento serão adicionados ao final do documento.

[Print sugerido: images/meus-modelos/como-configurar-arquivos-no-modelo-de-documento/01-adicionar-arquivo.png | Instrução: mostrar a área de arquivos do modelo com o botão Adicionar destacado.]

## 2. Informar a descrição

Preencher a descrição que será exibida para o usuário na fase de preenchimento do documento.

[Print sugerido: images/meus-modelos/como-configurar-arquivos-no-modelo-de-documento/02-descricao-arquivo.png | Instrução: mostrar o campo de descrição da solicitação de arquivo destacado.]

## 3. Permitir múltiplos arquivos, se necessário

Para permitir mais de um anexo no mesmo campo, marcar **Permitir múltiplos arquivos**.

[Print sugerido: images/meus-modelos/como-configurar-arquivos-no-modelo-de-documento/03-permitir-multiplos-arquivos.png | Instrução: mostrar a opção Permitir múltiplos arquivos destacada.]

## Resultado esperado

O modelo passa a solicitar arquivos durante o preenchimento do documento.
