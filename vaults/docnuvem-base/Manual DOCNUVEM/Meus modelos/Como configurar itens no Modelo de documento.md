# Como configurar itens no Modelo de documento

Os itens do modelo representam os campos que serão preenchidos pelo usuário ao criar um documento a partir do modelo.

## 1. Adicionar um item

Na área de itens do modelo, clicar em **Adicionar**.

[Print sugerido: images/meus-modelos/como-configurar-itens-no-modelo-de-documento/01-adicionar-item.png | Instrução: mostrar a área de itens do modelo de documento com o botão Adicionar destacado.]

## 2. Informar a descrição

Preencher a descrição do item.

Essa descrição será exibida para o usuário durante o preenchimento do documento.

[Print sugerido: images/meus-modelos/como-configurar-itens-no-modelo-de-documento/02-descricao-do-item.png | Instrução: mostrar o campo de descrição do item destacado.]

## 3. Escolher o tipo do item

Selecionar o tipo do item.

Entre os tipos mais usados estão **Caixa de texto**, **Data** e **Caixa de seleção múltipla**.

[Print sugerido: images/meus-modelos/como-configurar-itens-no-modelo-de-documento/03-tipo-do-item.png | Instrução: mostrar o campo de tipo do item com exemplos de opções disponíveis.]

## 4. Associar metadado e termo

Se necessário, selecionar o metadado associado ao item.

Também informar o **Nome do termo**, que será usado como TAG no template do documento.

[Print sugerido: images/meus-modelos/como-configurar-itens-no-modelo-de-documento/04-metadado-e-termo.png | Instrução: mostrar os campos de metadado associado e Nome do termo destacados.]

## 5. Definir obrigatoriedade

Marcar se o item será de preenchimento obrigatório.

[Print sugerido: images/meus-modelos/como-configurar-itens-no-modelo-de-documento/05-item-obrigatorio.png | Instrução: mostrar a opção de item obrigatório destacada.]

## Resultado esperado

O item fica configurado para preenchimento durante a criação do documento.
