# Como configurar pastas no Modelo de diretório

Use este guia para montar a estrutura de pastas de um modelo de diretório.

## 1. Abrir o modelo

Acessar a listagem de **Modelo de diretório** e selecionar o modelo que será configurado.

[Print sugerido: images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/01-modelo-aberto.png | Instrução: mostrar o modelo de diretório aberto para configuração.]

## 2. Abrir o menu de ações

Clicar em **Ações** para visualizar as opções disponíveis.

Nesse menu, é possível criar, remover e renomear pastas. Também é possível configurar regras de **Envio Inteligente** para as pastas do modelo.

[Print sugerido: images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/02-menu-acoes.png | Instrução: mostrar o menu Ações aberto com as opções de criar, remover, renomear e configurar Envio Inteligente.]

## 3. Criar uma pasta

Clicar em **Ações** e depois em **Criar pasta**.

Na janela exibida, informar o nome da pasta e clicar em **Criar pasta**.

[Print sugerido: images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/03-criar-pasta.png | Instrução: mostrar a janela de criação de pasta com o campo de nome e o botão Criar pasta destacados.]

## 4. Criar subpastas

Para criar uma subpasta, clicar sobre o nome da pasta pai e repetir o processo de criação de pasta.

[Print sugerido: images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/04-criar-subpasta.png | Instrução: mostrar uma pasta selecionada e a criação de uma subpasta abaixo dela.]

## 5. Renomear ou excluir uma pasta

Selecionar a pasta pelo checkbox ao lado do ícone da pasta.

Depois, clicar em **Ações** e escolher a opção de renomear ou excluir.

[Print sugerido: images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/05-renomear-ou-excluir-pasta.png | Instrução: mostrar uma pasta marcada pelo checkbox e o menu Ações com as opções de renomear e excluir destacadas.]

## Resultado esperado

A estrutura do modelo fica organizada com as pastas e subpastas necessárias.
