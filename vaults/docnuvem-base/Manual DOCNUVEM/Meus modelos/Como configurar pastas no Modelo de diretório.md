# Como configurar pastas no Modelo de diretório

Use este guia para montar a estrutura de pastas de um modelo de diretório.

## 1. Abrir o modelo

Acessar a listagem de **Modelo de diretório** e selecionar o modelo que será configurado.

![[Manual DOCNUVEM/images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/01-modelo-aberto.png]]

*Figura 1. Modelo de diretório aberto para configuração.*

## 2. Abrir o menu de ações

Clicar em **Ações** para visualizar as opções disponíveis.

Nesse menu, é possível criar, remover e renomear pastas. Também é possível configurar regras de **Envio Inteligente** para as pastas do modelo.

![[Manual DOCNUVEM/images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/02-menu-acoes.png]]

*Figura 2. Menu Ações aberto, com as opções de criar, remover e renomear pastas e de configurar regras de Envio Inteligente.*

## 3. Criar uma pasta

Clicar em **Ações** e depois em **Criar pasta**.

Na janela exibida, informar o nome da pasta e clicar em **Criar pasta**.

![[Manual DOCNUVEM/images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/03-criar-pasta.png]]

*Figura 3. Janela Nova pasta, com o campo de nome e o botão Criar pasta.*

## 4. Criar subpastas

Para criar uma subpasta, clicar sobre o nome da pasta pai e repetir o processo de criação de pasta.

![[Manual DOCNUVEM/images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/04-criar-subpasta.png]]

*Figura 4. Pasta selecionada no modelo, para criar uma subpasta abaixo dela.*

## 5. Renomear ou excluir uma pasta

Selecionar a pasta pelo checkbox ao lado do ícone da pasta.

Depois, clicar em **Ações** e escolher a opção de renomear ou excluir.

![[Manual DOCNUVEM/images/meus-modelos/como-configurar-pastas-no-modelo-de-diretorio/05-renomear-ou-excluir-pasta.png]]

*Figura 5. Pasta marcada pelo checkbox, com o botão Ações para renomear ou excluir.*

## Resultado esperado

A estrutura do modelo fica organizada com as pastas e subpastas necessárias.
