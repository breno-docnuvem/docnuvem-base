# Como excluir um Modelo de diretório

Use este guia para remover um modelo de diretório cadastrado.

## 1. Localizar o modelo

Acessar a listagem de **Modelo de diretório** e usar o balão **Filtrar** para encontrar o registro.

[Print sugerido: images/meus-modelos/como-excluir-um-modelo-de-diretorio/01-filtrar-modelo.png | Instrução: mostrar a listagem de modelos de diretório com o filtro aberto.]

## 2. Acionar a exclusão

Na coluna **Ações**, clicar no ícone de lixeira do modelo.

[Print sugerido: images/meus-modelos/como-excluir-um-modelo-de-diretorio/02-acao-excluir.png | Instrução: mostrar a coluna Ações com o ícone de lixeira destacado.]

## 3. Confirmar a exclusão

Na notificação exibida pelo sistema, confirmar a exclusão.

[Print sugerido: images/meus-modelos/como-excluir-um-modelo-de-diretorio/03-confirmar-exclusao.png | Instrução: mostrar a mensagem de confirmação de exclusão com a opção de confirmar destacada.]

## Resultado esperado

O modelo de diretório é removido da listagem.
