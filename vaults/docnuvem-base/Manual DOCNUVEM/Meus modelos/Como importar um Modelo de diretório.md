# Como importar um Modelo de diretório

Use a importação para criar um modelo a partir de uma estrutura de pastas já existente em [[Meus documentos]].

## 1. Acessar a importação

Na tela de modelo de diretório, clicar em **Importar**.

[Print sugerido: images/meus-modelos/como-importar-um-modelo-de-diretorio/01-botao-importar.png | Instrução: mostrar a tela de modelos de diretório com o botão Importar destacado.]

## 2. Escolher o diretório de origem

O sistema lista os diretórios que estão na raiz de **Meus documentos**.

Clicar no diretório pai que contém a estrutura que será importada.

[Print sugerido: images/meus-modelos/como-importar-um-modelo-de-diretorio/02-escolher-diretorio-origem.png | Instrução: mostrar a listagem de diretórios disponíveis para importação com um diretório pai destacado.]

## 3. Confirmar a importação

Concluir a importação conforme a confirmação exibida pelo sistema.

[Print sugerido: images/meus-modelos/como-importar-um-modelo-de-diretorio/03-confirmar-importacao.png | Instrução: mostrar a etapa de confirmação ou conclusão da importação do modelo de diretório.]

## Resultado esperado

A hierarquia de pastas selecionada é importada para o modelo de diretório.
