# Modelo de diretório

O **Modelo de diretório** permite criar estruturas de pastas padronizadas e reutilizáveis no Docnuvem.

Use modelos de diretório para manter a organização de setores, projetos ou empresas, evitando recriar manualmente a mesma hierarquia de pastas em diferentes contextos.
