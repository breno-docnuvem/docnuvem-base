# Modelo de solicitação

O **Modelo de solicitação** permite padronizar solicitações de documentos no Docnuvem.

Use esta funcionalidade para definir previamente quais documentos serão solicitados, por quanto tempo a solicitação ficará disponível e como os arquivos recebidos serão organizados.
