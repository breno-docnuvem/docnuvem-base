# Calendário de Tarefas

A tela de Calendário de Tarefas permite visualizar as tarefas em formato de calendário, facilitando o acompanhamento de prazos e vencimentos.

Usuários administradores podem visualizar todas as tarefas. Usuários não administradores visualizam apenas as tarefas em que são relatores ou responsáveis.

No calendário, o usuário relator pode arrastar o card de uma tarefa para alterar sua data de vencimento. Também é possível usar o filtro para visualizar somente as tarefas de um quadro específico, seguindo o mesmo funcionamento do filtro do [[Quadro Kanban]].
