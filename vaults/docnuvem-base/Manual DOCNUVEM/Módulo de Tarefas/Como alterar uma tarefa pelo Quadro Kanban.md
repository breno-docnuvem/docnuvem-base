# Como alterar uma tarefa pelo Quadro Kanban

No [[Quadro Kanban]], é possível acessar uma tarefa para consultar suas informações, realizar ajustes e acompanhar sua execução. Essa visualização é especialmente importante para os usuários responsáveis pela tarefa, pois reúne as ações necessárias para o andamento da atividade.

## 1. Acessar a tarefa

Para abrir uma tarefa, clique no card correspondente dentro do quadro.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-alterar-uma-tarefa-pelo-quadro-kanban/01-card-da-tarefa.png]]

*Figura 1. Card da tarefa no Quadro Kanban.*

## 2. Alterar as informações da tarefa

Ao abrir a tarefa, é possível visualizar e alterar suas principais informações, como nome, prioridade, prazo, valor, descrição, arquivos, responsáveis, atribuições e setores vinculados.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-alterar-uma-tarefa-pelo-quadro-kanban/02-dados-da-tarefa.png]]

*Figura 2. Informações da tarefa abertas pelo Quadro Kanban.*

## 3. Usar o chat da tarefa

A tarefa também conta com um chat para troca de mensagens entre responsáveis, relator e aprovadores.

As mensagens registradas nesse chat podem ser usadas para enviar considerações, dúvidas ou solicitações relacionadas à tarefa. Os usuários envolvidos serão notificados sobre as interações.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-alterar-uma-tarefa-pelo-quadro-kanban/03-chat-da-tarefa.png]]

*Figura 3. Chat da tarefa.*

## 4. Consultar o histórico

Na mesma visualização, é possível consultar o histórico da tarefa para acompanhar as alterações e movimentações realizadas.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-alterar-uma-tarefa-pelo-quadro-kanban/04-historico-da-tarefa.png]]

*Figura 4. Histórico da tarefa.*

## 5. Mover a tarefa entre etapas

Na visualização do quadro, os cards podem ser arrastados entre as etapas para atualizar o andamento da tarefa.

![[05-arraste-entre-etapas.png]]

*Figura 5. Movimentação da tarefa entre etapas do Quadro Kanban.*

Caso a etapa de destino tenha aprovação ativada, a tarefa só avançará depois que os responsáveis pela aprovação validarem a movimentação. Os usuários envolvidos serão notificados durante esse processo.
