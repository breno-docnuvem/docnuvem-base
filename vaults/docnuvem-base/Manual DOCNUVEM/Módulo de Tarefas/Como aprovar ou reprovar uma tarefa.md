# Como aprovar ou reprovar uma tarefa

Para aprovar ou reprovar uma tarefa, acesse a tela de [[Fluxo de aprovação]] e localize o registro que deseja analisar.

## 1. Acessar a tarefa

Na listagem do fluxo de aprovação, clique na ação disponível para abrir a tarefa.

![[01-listagem-acao-acessar.png]]

*Figura 1. Ação para acessar uma tarefa no Fluxo de aprovação.*

## 2. Verificar as informações

Na tela aberta, confira as informações da tarefa e acompanhe seu andamento antes de tomar uma decisão.

![[02-visualizacao-da-tarefa.png]]

*Figura 2. Visualização da tarefa no Fluxo de aprovação.*

## 3. Usar o chat da tarefa

Se necessário, use o chat para trocar mensagens com responsáveis e aprovadores.

As mensagens enviadas pelo chat notificam os usuários envolvidos no fluxo.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-aprovar-ou-reprovar-uma-tarefa/03-chat-da-tarefa.png]]

*Figura 3. Chat da tarefa no Fluxo de aprovação.*

## 4. Aprovar a tarefa

Para aprovar a movimentação, clique na opção de aprovação disponível na tela.

Depois da aprovação, a tarefa avançará automaticamente para a próxima etapa do quadro.

![[04-aprovar-tarefa.png]]

*Figura 4. Opção para aprovar a tarefa.*

## 5. Reprovar a tarefa

Para reprovar a movimentação, clique na opção de reprovação e informe as considerações sobre o motivo da reprovação.

![[05-reprovar-tarefa.png]]

*Figura 5. Opção para reprovar a tarefa e informar considerações.*
