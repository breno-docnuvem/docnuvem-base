# Como criar um projeto

Para criar um novo projeto, acesse a tela de [[Projetos]] e siga os passos abaixo.

## 1. Cadastrar novo projeto

Clique em **Cadastrar novo projeto**.

![[01-listagem-cadastrar-novo-projeto.png]]

*Figura 1. Botão Cadastrar novo projeto na listagem de projetos.*

## 2. Informar os dados do projeto

Na tela de cadastro, informe o nome do projeto.

Também é possível definir por quanto tempo uma tarefa concluída ficará visível no quadro antes de ser ocultada. Esse campo é opcional.

![[02-dados-do-projeto.png]]

*Figura 2. Campos de nome e tempo de visibilidade do projeto.*

## 3. Cadastrar as etapas

Para adicionar as etapas do quadro, clique em **Cadastrar nova etapa** e informe o nome da etapa.

Depois de cadastrada, a etapa aparecerá abaixo junto das demais etapas do projeto.

Durante a criação do projeto, as etapas podem ser arrastadas para organizar a ordem em que aparecerão no quadro Kanban.

![[03-cadastro-de-etapas.png]]

*Figura 3. Área para cadastrar e organizar as etapas do projeto.*

## 4. Configurar aprovação da etapa

Caso uma etapa precise passar por fluxo de aprovação, ative a opção **Exigir aprovação** nessa etapa.

Depois disso, adicione no campo exibido os usuários que serão responsáveis pela aprovação.

![[04-aprovacao-da-etapa.png]]

*Figura 4. Configuração de aprovação da etapa.*

## 5. Salvar o projeto

Depois de revisar as informações, clique em **Salvar** para criar o projeto.

![[05-botao-salvar.png]]

*Figura 5. Botão Salvar para criar o projeto.*
