# Como criar uma tarefa pelo Calendário de Tarefas

Na tela de [[Calendário de Tarefas]], é possível criar tarefas pelo botão **Criar tarefa** ou clicando diretamente em um dia do calendário.

## 1. Iniciar a criação da tarefa

Clique em **Criar tarefa** ou selecione o dia do calendário em que a tarefa deve ser criada.

![[01-criar-tarefa-ou-dia-calendario.png]]

*Figura 1. Opções para criar uma tarefa pelo calendário.*

## 2. Informar os dados da tarefa

Preencha os dados da tarefa da mesma forma que na criação pela tela de [[Tarefas]].

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa-pelo-calendario-de-tarefas/02-formulario-criacao.png]]

*Figura 2. Formulário de criação de tarefa aberto pelo calendário.*

## 3. Salvar a tarefa

Depois de revisar as informações, clique em **Salvar** para criar a tarefa.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa-pelo-calendario-de-tarefas/03-botao-salvar.png]]

*Figura 3. Botão Salvar para criar a tarefa.*
