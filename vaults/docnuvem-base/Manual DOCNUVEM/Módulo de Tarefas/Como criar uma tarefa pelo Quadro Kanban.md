# Como criar uma tarefa pelo Quadro Kanban

Para criar uma tarefa pelo Quadro Kanban, acesse a tela de [[Quadro Kanban]] e selecione o projeto que deseja visualizar.

## 1. Escolher a etapa inicial

No quadro, localize a etapa em que a tarefa deve ser criada e clique no botão **+**.

![[01-botao-mais-etapa-inicial.png]]

*Figura 1. Botão para criar uma tarefa na etapa inicial do Quadro Kanban.*

## 2. Informar os dados da tarefa

Depois de clicar no botão **+**, preencha os dados da tarefa da mesma forma que na criação pela tela de [[Tarefas]].

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa-pelo-quadro-kanban/02-formulario-criacao.png]]

*Figura 2. Formulário de criação de tarefa aberto pelo Quadro Kanban.*

## 3. Salvar a tarefa

Depois de revisar as informações, clique em **Salvar** para criar a tarefa na etapa selecionada.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa-pelo-quadro-kanban/03-botao-salvar.png]]

*Figura 3. Botão Salvar para criar a tarefa na etapa selecionada.*
