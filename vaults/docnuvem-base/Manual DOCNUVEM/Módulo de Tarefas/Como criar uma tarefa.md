# Como criar uma tarefa

Para criar uma nova tarefa, acesse a tela de [[Tarefas]] e siga os passos abaixo.

## 1. Cadastrar nova tarefa

Clique em **Cadastrar nova tarefa**.

![[01-listagem-cadastrar-nova-tarefa.png]]

*Figura 1. Botão Cadastrar nova tarefa na listagem de tarefas.*

## 2. Informar os dados da tarefa

Na nova tela, preencha os dados da tarefa que será criada.

Informe o nome da tarefa, a prioridade, o prazo, o valor, o projeto do qual a tarefa fará parte e a etapa do projeto em que a tarefa será iniciada.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa/02-formulario-dados-principais.png]]

*Figura 2. Campos principais do formulário de criação da tarefa.*

Na parte inferior da tela, também é possível preencher informações adicionais da tarefa:

- **Descrição:** campo de texto para adicionar a descrição da tarefa.
- **Arquivo:** campo para adicionar arquivos que poderão ser acessados pelos responsáveis.
- **Responsáveis:** campo para definir os usuários responsáveis pela execução da tarefa.
- **Atribuições:** campo para vincular um ou mais contatos do sistema à tarefa, como fornecedor ou encarregado.
- **Setores:** campo para vincular um ou mais setores do sistema à tarefa, como o setor responsável.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-criar-uma-tarefa/03-formulario-informacoes-adicionais.png]]

*Figura 3. Informações adicionais do formulário de criação da tarefa.*

## 3. Salvar a tarefa

Depois de revisar as informações, clique em **Salvar** para criar a tarefa.

![[04-botao-salvar.png]]

*Figura 4. Botão Salvar para criar a tarefa.*
