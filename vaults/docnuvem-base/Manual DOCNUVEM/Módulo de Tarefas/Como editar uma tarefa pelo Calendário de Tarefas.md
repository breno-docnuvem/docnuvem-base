# Como editar uma tarefa pelo Calendário de Tarefas

Na tela de [[Calendário de Tarefas]], é possível acessar uma tarefa para consultar suas informações, realizar ajustes e acompanhar sua execução.

## 1. Acessar a tarefa

Para abrir uma tarefa, clique no card correspondente dentro do calendário.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-editar-uma-tarefa-pelo-calendario-de-tarefas/01-card-da-tarefa.png]]

*Figura 1. Card da tarefa no Calendário de Tarefas.*

## 2. Alterar as informações da tarefa

Ao abrir a tarefa, é possível visualizar e alterar suas principais informações, como nome, prioridade, prazo, valor, descrição, arquivos, responsáveis, atribuições e setores vinculados.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-editar-uma-tarefa-pelo-calendario-de-tarefas/02-dados-da-tarefa.png]]

*Figura 2. Informações da tarefa abertas pelo calendário.*

## 3. Usar o chat da tarefa

A tarefa também conta com um chat para troca de mensagens entre responsáveis, relator e aprovadores.

As mensagens registradas nesse chat podem ser usadas para enviar considerações, dúvidas ou solicitações relacionadas à tarefa. Os usuários envolvidos serão notificados sobre as interações.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-editar-uma-tarefa-pelo-calendario-de-tarefas/03-chat-da-tarefa.png]]

*Figura 3. Chat da tarefa.*

## 4. Consultar o histórico

Na mesma visualização, é possível consultar o histórico da tarefa para acompanhar as alterações e movimentações realizadas.

![[Manual DOCNUVEM/images/modulo-de-tarefas/como-editar-uma-tarefa-pelo-calendario-de-tarefas/04-historico-da-tarefa.png]]

*Figura 4. Histórico da tarefa.*

## 5. Alterar o vencimento pelo calendário

O usuário relator pode arrastar o card da tarefa para outro dia do calendário para alterar sua data de vencimento.

![[05-arraste-vencimento.png]]

*Figura 5. Alteração do vencimento da tarefa pelo calendário.*
