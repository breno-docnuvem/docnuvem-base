# Fluxo de aprovação

A tela de Fluxo de aprovação permite acompanhar as tarefas que dependem de aprovação para avançar no quadro Kanban. Essa funcionalidade ajuda a garantir que a movimentação entre etapas seja validada pelos usuários definidos como aprovadores.

Na listagem, é possível verificar as principais informações das tarefas em aprovação:

- **Nome**
- **Etapa**
- **Projeto**
- **Status do fluxo**
- **Participação**
- **Início**
- **Fim**
- **Protocolo**

Ao clicar na ação disponível em uma tarefa, o Docnuvem abre a tela de visualização do fluxo. Nessa tela, é possível consultar as informações da tarefa, acompanhar seu andamento, usar o chat para troca de mensagens entre responsáveis e aprovadores, aprovar o avanço da tarefa ou reprovar a solicitação com considerações.

As mensagens enviadas pelo chat geram notificações para os usuários envolvidos no fluxo.
