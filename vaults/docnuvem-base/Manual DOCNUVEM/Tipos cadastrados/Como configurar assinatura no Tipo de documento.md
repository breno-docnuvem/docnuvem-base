# Como configurar assinatura no Tipo de documento

Use as configurações de assinatura para definir comportamentos padrão quando um documento desse tipo for enviado para assinatura.

## 1. Acessar a aba de assinatura

No cadastro do tipo de documento, abrir a aba **Configurações de assinatura**.

[Print sugerido: images/tipos-cadastrados/como-configurar-assinatura-no-tipo-de-documento/01-aba-configuracoes-assinatura.png | Instrução: mostrar a aba Configurações de assinatura aberta no cadastro de tipo de documento.]

## 2. Definir regras da solicitação

Configurar as opções de assinatura disponíveis para o tipo de documento.

Entre as opções, é possível permitir a solicitação ao identificar o tipo do documento, definir a quantidade de dias para vencimento da assinatura, escolher o tipo de assinatura padrão, exigir rubrica e considerar a ordem de assinatura.

[Print sugerido: images/tipos-cadastrados/como-configurar-assinatura-no-tipo-de-documento/02-regras-de-assinatura.png | Instrução: mostrar as opções de solicitação, vencimento, tipo de assinatura, rubrica e ordem de assinatura destacadas.]

## 3. Adicionar assinantes

Para adicionar assinantes padrão ao tipo de documento, clicar em **Adicionar**.

Depois, selecionar um usuário já cadastrado no sistema.

[Print sugerido: images/tipos-cadastrados/como-configurar-assinatura-no-tipo-de-documento/03-adicionar-assinante.png | Instrução: mostrar a área de assinantes com o botão Adicionar e o campo de seleção de usuário destacados.]

## 4. Salvar as configurações

Após revisar as regras de assinatura e os assinantes, clicar em **Salvar**.

[Print sugerido: images/tipos-cadastrados/como-configurar-assinatura-no-tipo-de-documento/04-salvar-configuracoes.png | Instrução: mostrar o botão Salvar na configuração de assinatura do tipo de documento.]

## Resultado esperado

Quando um documento desse tipo for enviado para assinatura, o Docnuvem poderá aplicar as configurações definidas.
