# Tipo de documento

O **Tipo de documento** permite classificar documentos e definir informações complementares, como metadados e configurações de assinatura.

Use este cadastro para manter os documentos organizados, facilitar buscas e aplicar regras específicas conforme a natureza de cada arquivo.
