# 05 - Quadro Kanban

## Duração sugerida

1 a 2 minutos.

## Objetivo

Mostrar como visualizar, criar e movimentar tarefas pelo Quadro Kanban.

## Tela inicial

Quadro Kanban aberto com um projeto selecionado.

## Roteiro

### Abertura

**Narração:**  
O Quadro Kanban mostra as tarefas em cards, separadas pelas etapas do projeto.

**Ação em tela:**  
Mostrar as colunas do quadro.

### Criar pelo quadro

**Narração:**  
Para criar uma tarefa direto no quadro, clique no botão de adicionar na etapa inicial.

**Ação em tela:**  
Clicar no botão de adicionar tarefa em uma coluna.

**Narração:**  
Preencha os dados da tarefa e salve. A tarefa será criada já dentro da etapa escolhida.

**Ação em tela:**  
Mostrar o formulário rapidamente e voltar ao quadro.

### Abrir e acompanhar

**Narração:**  
Para consultar uma tarefa, clique no card. Aqui você pode ver e alterar informações como nome, prioridade, prazo, valor, descrição, arquivos, responsáveis, atribuições e setores.

**Ação em tela:**  
Abrir o card e mostrar os dados principais.

**Narração:**  
Na mesma tela, também é possível usar o chat da tarefa e consultar o histórico.

**Ação em tela:**  
Mostrar chat e histórico.

### Movimentar

**Narração:**  
Para atualizar o andamento, arraste o card para outra etapa.

**Ação em tela:**  
Arrastar uma tarefa entre colunas.

**Narração:**  
Se a etapa de destino tiver aprovação, a tarefa só avançará depois da validação dos aprovadores.

**Ação em tela:**  
Mostrar a etapa de destino ou uma tarefa que exija aprovação.

### Fechamento

**Narração:**  
O quadro é a forma mais visual de acompanhar o andamento das tarefas do projeto.

**Ação em tela:**  
Mostrar o quadro completo.

## Checklist de gravação

- Escolher um projeto com poucas etapas visíveis.
- Usar uma tarefa de teste para movimentar.
- Mostrar o antes e o depois da movimentação.
